One emoji, nothing else, standing in for the trip of my dreams: 🌅 — sunrise breaking over open water, the first morning of a holiday far from home. A judge pairs the emojis two at a time and the most evocative one takes the whole reward.

`main.ts` writes exactly that single emoji (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints the same emoji plus a newline to stdout.

## Run

```sh
node main.ts
```
